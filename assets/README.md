# Dossier assets/

Ce dossier contient les images utilisées par le portfolio statique
(`/junior-portfolio/index.html`).

## Photo de profil

`bakary-toure.jpg` est déjà présente (copie de la photo réelle fournie).
Pour la remplacer, déposez simplement un nouveau fichier au même nom et au
même emplacement :

```
assets/bakary-toure.jpg
```

Format recommandé : carré (ex. 800x800px), poids < 500 Ko.

## Images des projets

`assets/projects/*.svg` contient des visuels génériques (placeholders) pour
les 7 cartes de la section Projets. Vous pouvez les remplacer par de vraies
captures d'écran (dashboards, graphiques, etc.) en gardant le même nom de
fichier, ou en mettant à jour le champ `image` correspondant dans
`translations.js`.

| Fichier | Projet |
| --- | --- |
| `dashboard-ventes.svg` | Dashboard Power BI — Ventes |
| `sql-performance.svg` | Analyse SQL des performances commerciales |
| `spss-stats.svg` | Analyse statistique SPSS |
| `excel-auto.svg` | Tableau de bord Excel automatisé |
| `stata-eco.svg` | Analyse STATA de données économiques |
| `tableau-viz.svg` | Visualisation Tableau interactive |
| `r-model.svg` | Modèle prédictif en R |

## Avatars des témoignages

`assets/testimonials/1.svg` à `6.svg` sont des avatars génériques
(initiales) pour les 6 témoignages fictifs. Remplaçables au même nom.
